# Three Scenarios
## Greenfield
Create URL and redirect functionality from scratch using task decomposition and Copilot-assisted implementation/tests.
## Brownfield
Improve the baseline redirect path with Redis caching while preserving database fallback; validate with regression/performance tests.
## Ambiguous
Interpret “Add analytics”: clarify click definition, dimensions, real-time expectations and retention. Choose V1 = click count + timestamp + short code, with optional user-agent/referrer events.
